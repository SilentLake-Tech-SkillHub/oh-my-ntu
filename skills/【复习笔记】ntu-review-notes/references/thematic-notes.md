# 分主题组织、深度与验收

## 主题应回答什么

一个主题围绕一项可理解、比较、计算或判断的知识问题展开。例如“如何识别和处理缺失值”可连接缺失机制、语义缺失、插补及评估污染；不是按某一周、某篇论文、某次考试给材料换名。跨周有联系的知识应汇合，原理或使用决策不同的问题应拆开。不要把多个互不相干的概念卡并列后称为完整分析。

按用户指定的课程和材料范围盘点教师讲义、配套代码、Tutorial和已取得的课堂证据，形成主题与来源定位的对应：哪些主题需要独立文档，哪些是其子问题，哪些只属阅读参考。完整课程重建应逐项说明来源中的实质内容落在哪个主题；只要求某一主题时不要扩成全课程。主题地图应进入可阅读的导航页，方便用户判断覆盖与缺口。内部来源清单和制作证据放临时工作区，不往课程目录塞治理文件。

## 独立学习的深度

每个主题要使未读过逐页译文的学生能够沿着解释完成该主题的实际任务。视内容需要，展开问题由来、核心概念、机制、公式中各量的含义、完整例子、方法选择、失败条件与相近概念区别。用因果和推理把段落连起来，而非每个概念只有定义、口诀和一个结论。结构应服务内容，不必所有主题套相同标题。

- 计算主题：至少展开一个完整可复算案例，保留输入、约定、中间步骤、结果和解释；选择会影响结果时说明约定。公式之后立即说明为什么这样计算、结果允许什么判断。
- 方法比较：比较共同任务、数据条件、关键机制、代价与失败原因，并给出情境选择；“适用于X”的短表不能替代解释。
- 分析或治理主题：沿一个具体案例走完证据、判断、控制与剩余局限。法规教学表述与现行法律意见分开；不把历史课件案例说成已核验的当前事实。
- 跨周联系：解释连接为什么成立，如预处理如何进入评估、稀有异常与少数类如何相遇；不能仅列“另见WeekN”。
- 自检：给需要推理或迁移的任务及可展开答案，答案解释依据和常见误区；不拿“能否说清……”的重复句替代教学。

教师原例、原文简化或错误、整理者自拟例子与补充解释须可区分。发现原稿数字或概念有问题，回原件核对并复算，不能为了保持表面一致照抄错误。主题内容按知识组织，文中按相关段落回链到教师文件及物理页、Cell或题号；只在文末列整份PDF不够精确。

## 成品组织和修复

文件名让用户打开前就知道知识主题。提供总导航和主题间链接；一份多主题总册或多份主题文档均可，尊重已有使用习惯。论文导读、全课程串讲等材料可作参考，但不能计作若干主题已经覆盖。修复误分类时先核对内容与依赖，保留有用内容至最新材料并修好出入链接；替换成功后移除被替代旧文件，不设历史版本区。不要用新链接继续把薄弱的旧摘要作为主题正文。

周度复习回答“这周学了什么、怎样连起来”；主题笔记回答“这个问题如何完整理解和解决”；考前速记回答“如何迅速唤起已学知识”。三者允许共享事实和来源，但必须有用途与深度差异。主题页不夹带与主题无关的模拟卷、考试状态或制作过程横幅。

## 验收应证明什么

1. **组织**：从教师来源出发逐项核对主题归属，检查漏项、重复与误分类；主题树不是根据旧文件数反推。
2. **教学**：逐篇检查学生能否从正文独立完成案例、解释步骤、区分相近方法并识别失效条件；数值复算。对每篇选一个迁移问题实际作答，用其暴露内容缺口。任何浅卡片或无解释的结论都不能因字数或模板齐全通过。
3. **呈现**：实际打开导航页及各主题页，检查长公式、表格、目录、来源跳转、自检展开、搜索/筛选和窄屏；修复实际显示缺陷。自动检查只证明其检查的项目。
4. **交付**：说明本次真正重做的范围、规则变化、验证和仍需用户审阅之处。不要宣称全课程验收或教师认可；不要让用户再要求一次才把规则应用到其指出的成品。
