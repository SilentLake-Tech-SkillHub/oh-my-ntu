# 04 复习笔记

读取 [通用默认合同](../../references/defaults.md)。默认二级目录：`01_周度回顾复习笔记`、`02_分主题分析笔记`，以及有实际内容才建立的 `03_【如有】代码分析与复习笔记`。产物需能回到教师文件与页/Cell/题号；不同维度要有真实内容差异，不复制同一文件或用链接替身。

周度回顾默认是一份完整 HTML：同页按 Week 分区、左侧或显著位置有可跳转目录，讲清该周主线、概念与联系。个人速记、03 的逐页预习 Notebook、纯代码手册不能冒充周度成品。主题笔记聚焦一项概念或跨周主题，比较原理、边界与应用，文件名明示主题。代码笔记仅在课程有代码时建立；按实际 Quiz/Midterm/Final 范围切分，先请用户确认每次考试范围，不能凭已有文件名假定。逐段解释函数/方法、参数、返回、原地修改、执行条件、输出与常见错误；运行结果来自实际执行或明确标推导。

Tutorial 的原件副本、翻译、讲解与解答 Notebook 属课前预习，按 [03 Tutorial 合集规则](../【课件预习笔记】ntu-courseware-to-notebook/SKILL.md) 放在 03；04 不另建 Tutorial 单元，也不复制其讲解。复习笔记可以引用 Tutorial 题号或 Cell 作为来源，链接指向 01 正本或 03 讲解。

有运行输出和数字结论时，可用 [只读数字审计工具](../../scripts/audit_notebook_numbers.py) 对照保存的输出，再人工逐条核对；它不能执行代码或证明数字正确，不是无数据产物的必跑步骤。验收按来源、实际页面/Notebook 渲染与用户可见内容分别说明。
