# 02 大作业初始化

读取 [通用默认合同](../../references/defaults.md)。新作业默认仅建立 `02_大作业/01_作业要求、DDL与评分标准/` 与 `02_大作业/02_提交模板/`；过程稿和成品以后随实际版本产生，不预建空壳。现有课程的事后整理方案不是新项目强制结构。

在 01 保存 Assignment Brief、Rubric、公告、页面截图等未改写原件，逐项提取目标、交付物、格式、字数/页数、个人或分组规则、DDL 与时区、提交入口、评分标准。给每条事实标官方原件、课堂口头、用户转述、本地推定或待确认及定位。截图名写清日期、课程、主题与来源；ZIP 名说明实际载体，不能只写 `review`。不从课程名称或旧项目猜截止时间和权重。

在 02 仅根据已确认要求制作提交模板；未知页数、格式或字段明确待确认。模板不得预填虚构实验、成绩或完成状态。若需访问已确认的学生平台，先告知 Computer Use 将查看的页面及只读范围；登录、OTP、提交由用户掌控。交付时说明哪些要求已从官方核验、哪些尚未核验，以及模板依赖哪些确认项。
