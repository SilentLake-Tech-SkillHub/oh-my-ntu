# 考试信息汇报合同

这份合同规定 `build_exam_briefing.py` 的输入格式，以及七段报告各自必须回答的问题。数据文件放在课程目录和 SKILL 包之外的临时区，图片路径相对数据文件书写。

## 七段内容清单

| 段 | 必须回答 | 典型来源 | 截图 |
|---|---|---|---|
| 1 时间、地点、座位 | 日期与时段；到场时间；机房或教室；座位或分机房规则（没有就写"未公布"）；迟到、缺考与补考；考后安排；同日其他考试 | 公告、考核页或 Quiz rules、Course Briefing、课堂口头 | 公告详情、Quiz rules 座位表、日程页 |
| 2 范围 | 考哪些周和章；每周主题和关键知识点；明确不在范围内的周；课程周与平台录播周的对应 | 课程信息页、公告、日程表、课堂口头 | 日程表或范围页、课程信息 |
| 3 题型 | 单选、多选、判断、填空、简答；开卷还是闭卷；能否用计算器；考不考代码；题量；是否题库抽题；答题原则 | Quiz rules、Sample Quiz、课堂口头 | 规则页、Sample 概览 |
| 4 计分 | 课程总评比例；本次总分；各题型的给分、部分分和倒扣规则（每题是否最低为 0）；没公布的比例写"未公布" | Briefing、考核页、Quiz rules、课堂口头 | Briefing 或规则页、带计分说明的样题 |
| 5 重点 | 课堂小测或样题逐题表（题目、选项、公布的答案、考点）；Sample Quiz；老师强调的知识点；Tutorial 在考试中的用法；明确不考的内容 | 录播画面与文字稿、Sample 作答记录 | 每道小测题的投屏帧、强调页、"不考"页 |
| 6 备考 | 按优先级列出要做的事，链接到本地成品（03、04、05、07）；考前清单 | 前五段与本地成品 | 一般不需要 |
| 7 原始内容对照 | 前五段引用的全部原文，加上来源登记（页面链接、文字稿文件、ID、截帧方式） | 自动汇总 | — |

每段的固定顺序是：结论表 → 截图 → 原文对照。原文对照可以折叠，第 7 段默认展开。

## 写作规则

- **结论先行**：表格第一列写"项目"，第二列写结论（关键值加粗），后面依次是依据和来源类型。
- **来源类型**只用五种：`official` 官方书面、`oral` 课堂口头、`previous` 往届录播、`local` 本地判断、`user` 用户转述。
- **冲突**单独写一张"冲突与提醒"，写明采用哪条、为什么。自动转写的识别错误写在中文意思里，原文照录。
- **不推算**：官方没写的比例、座位和答案，写"未公布"或标为本地判断，并给出理由。
- **原文摘录**只截取说明事实所需的几句，并标出场次和时间戳（时:分:秒，可写成区间）。
- **隐私与安全**：不放会议密码、签名令牌、他人信息。用户本人的作答记录只在本地报告中使用。

## 数据格式

```json
{
  "page_title": "浏览器标签标题",
  "title": "页面大标题",
  "subtitle": "课程全名 · 考试日 · 依据的数据截至时间",
  "status_note": "最新官方依据与总体结论（可选）",
  "summary": [{"label": "时间", "value": "…"}],
  "sections": [
    {
      "id": "s1", "short": "1 时间地点座位", "title": "1. 考试时间、地点、座位安排",
      "intro": "可选说明",
      "blocks": [
        {"heading": "可选小标题",
         "table": {"columns": ["项目", "结论", "依据", "类型"],
                   "rows": [["日期", "**…**", "…", {"badge": "official"}]]},
         "figures": [{"src": "img/x.jpg", "type": "official", "caption": "…",
                      "source": "页面或录播与时间戳", "link": "可选", "wide": false}],
         "notes": ["…"],
         "originals": [{"type": "oral", "source": "[场次](相对路径)", "when": "0:04:06–0:04:14",
                        "en": "原文", "zh": "中文意思"}],
         "originals_open": false}
      ]
    }
  ],
  "footer": "生成日期、标签说明、使用限制"
}
```

行内文字支持 `**加粗**`、`` `代码` ``、`[文字](链接)` 和换行 `\n`。表格单元格写成 `{"badge": "<类型>"}` 时渲染为来源标签。第 7 段由数据生成脚本汇总前五段的 `originals` 并去重。

## 取帧清单格式（fetch_recording_frames.py）

每行一个制表符分隔的记录：`名称  entryId  时:分:秒  版式`，版式为 `full`、`composite` 或 `camera`。接口模板用 `{entry}`、`{width}`、`{sec}` 三个占位符，从频道页缩略图地址改写得到。
