# 06 课堂录播字幕与课程信息

读取 [通用默认合同](../../references/defaults.md)。默认按 `06_课堂录播字幕/WeekNN/` 放每场原始字幕及同周的课堂讲解笔记；原文和 AI 整理件分开，不覆盖。字幕只经官方学生可见附件入口下载，按字节保留，登记录播平台 ID、附件 ID、获取时间、大小、哈希。没有官方下载控制时不得绕过签名链接或分段流；不下载音视频，不自行 ASR 重转写来冒充官方字幕。未发布或未获取的场次明确列缺口。

以字幕、公告和课件作证据提炼课堂重点，记录课次、时间戳、原文片段或课件页。检索课程信息、考试范围、教师强调的知识点或 Presentation 安排时，除课件与学生平台外，搜索已获取的同学期课堂字幕；命中后回查原文，记录字幕文件、Week／场次及时间戳（无时间戳则记可定位的段落）。考试重点的“老师说必考”与本地判断严格分开；字幕中的口头表述不自动覆盖正式公告，冲突须并列呈现。没有相关字幕时如实标注未取得，不以此替代或停止其他来源核对。课程信息汇总放 06 根目录：课表时间、教室/线上地点、课程目标和考核构成等逐条标来源。日历 `.ics` 不是本 Skill 的默认产物；只有用户明确要求日历导入或导出时，才以已核实的日程制作并标明线上/实体、时区和提醒。作为导入中间件时，确认实际日历事件后按默认合同清理，不把留在课程根目录的 `.ics` 当成课程成品。

考试、Quiz、Final、Presentation 的时间、地点、范围、权重、分组及其原通知也归 06，不因原文件属性放进 01；真实材料存在才建相应区。按主 SKILL 先识别学生平台及课程页；为 07 核实范围时先逐页核对课程说明、第一份讲义和课程时间表中的文字与图片表格，再主动只读查看公告、考核页和模块，并检索已获取的同学期课堂字幕，与本地官方原件比较学期与版本。平台课程列表的首屏不是完整检索结果，先搜索或筛选，再判断可访问性。逐次记录页面、时间、字幕课次与时间戳、原文和冲突；没有明说范围时，不把讲课顺序当成正式范围。查不到时区分未检查、不可访问、页面未见及确认未发布。区别官方公告、课堂口头、用户转述、推定与待确认，旧课程的时间/比例不得搬用到新课。官方范围缺失时，07 可提出分次考试的本地候选范围，但须记录用户确认，不能把候选范围写成官方范围。

使用 Computer Use 前告诉用户将访问学生平台或录播平台的哪些页面及只读边界；登录由用户完成。取得字幕后核对官方场次清单和本地实体，内容笔记按字幕位置回查。
