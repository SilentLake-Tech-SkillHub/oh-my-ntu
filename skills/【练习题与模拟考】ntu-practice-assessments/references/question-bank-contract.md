# 出题与验收细则

## 交互、评分和题面

交互类型仅单选、多选、填空。代码阅读、纠错、匹配、图表判断是内容呈现，不得拿标签冒充不同作答方式。单选/填空按登记标准答案及合理格式变体评分；多选少选且无错选时按正确项比例给分，任一错选为零。分数可由结构化数据复算。题干和选项应是自然、完整、无自指的英文；考生无需知道“lecture 说了什么”才能理解条件。代码显示用等宽样式，写全库、对象、括号、运行环境和必要前置条件，不把 `normal`、`choice` 等孤立内部词塞入题面。

## 四条内容线

1. 细节题按教师课件或 Notebook 的独立教学点覆盖概念与原代码。定义、特点、条件、分类、函数名、参数、默认值、返回、副作用和输出要被直接考到；仅在解析提到不算覆盖。原代码保留教师结构、说明原码/修正版/改编，确定性输出用课程运行环境验证。重复、空白或纯格式点登记排除原因。
2. 主题练习按概念或跨周主题，默认每主考点约五题，避免换皮重复。
3. 周练按 Week、不按 Chapter 分卷；默认 A/B 卷合计覆盖已登记主考点。教师原文定义填空默认占每套 15%–25%，须登记原英文句、挖空位置、答案/变体和精确页码；语句不足以唯一确定答案时接受明确变体或改题。定义证据不足不硬凑比例。
4. Quiz/Final 模拟卷先确认每次考试范围，默认 A/B/C，每套 20 题/100 分，跨套避免换皮重复，卷内覆盖范围内各 Week 和主要主题。按该课程真实权重组卷，绝不默认套用某一门课的比例。参考教师 Sample 的出题方式（图表误导判断、表格概念匹配、代码判断图形等），用源图局部或按真实数据重构图表，不用整页 PPT 截图或无关通用占位图。

## 官方范围缺失时的用户确认兜底

只有逐页查过课程说明与首份讲义、核对当期课程日程及学生平台的公告／考核模块，并检索已获取的同学期**原始字幕文件**后，确实没有该场考试的明确范围，才提出以下**本地模拟卷候选范围**：第一次考试覆盖该次考试前全部课程内容；第二次考试只覆盖第一次考试后、第二次考试前的课程内容，默认不重复第一次考试已覆盖部分。字幕若有教师明确说明，应记录文件、课次和时间戳并与正式公告核对；仅有字幕口头范围而无正式公告时，向用户说明来源并确认是否据此编卷，不直接套用日期兜底。不得把未取得字幕写成已查无范围，也不得把口头表述默认为正式公告。按当期日期与已取得的课程材料列出具体 Week、主题和起止边界，说明这不是教师公布的考试范围。向用户明确询问是否按该候选范围出卷；获得确认后才执行，并在试卷标注“用户确认的本地兜底范围”。用户当前 Prompt 或正式考试说明另有范围时，以其明确要求或正式说明为准，不使用此兜底。

## Sample、来源和答案

Sample 从用户文件或已确认学生平台的官方学生可见页只读获取，先告知 Computer Use 范围；记录课程、Quiz、来源 URL/文件、获取日期、题号、题面/选项、是否有官方答案及证据。一次性 attempt ID 和个人成绩留在本次交付，不写长期规则。原题与衍生题明确分开，不能由个人选择推断正确答案。每题记录知识点及教师文件和 PDF 页/slide/Cell；中文与英文解析都解释每个选项，说明证据与推定边界。

## 离线页面的状态与验收

初始 DOM 不包含答案/解析；全部必答项完成前提交禁用；整套提交才插入答案、解析、知识点和来源；重置后重新锁定。自动保存草稿，刷新或关闭可恢复；重置要提示影响且历史成绩、错题记录不被无提示抹除。历史包含题目版本和当次选项顺序。反馈首先列出选项字母，并分别列你的答案、正确答案、漏选与错选，不只拼接全文。HTML 离线可用，无外部 CDN、`<base>` 劫持、断链或重复 ID。

真实浏览器至少检查空白卷、部分作答、全部作答、提交后、刷新恢复、重置、历史及错题，桌面和手机无横向溢出，键盘焦点可见，状态不只用颜色表达。截图给用户，不能把题数、覆盖映射、自动测试和界面检查混为一项验收。默认视觉可参考浅灰底白色考试纸、紧凑题卡与清晰选项，但用户指定风格优先。
