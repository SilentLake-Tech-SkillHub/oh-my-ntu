# 课堂小测样题：每堂课的小测作为一套 Sample Quiz

老师在课上用 Wooclap、Kahoot、Mentimeter、Slido、Teams 投票或举手投票出的小测，题目出自授课老师本人，属于**教师 Sample Quiz 的一部分**。它们和学生平台上的 Sample Quiz 同级，都与本地原创的模拟题分开存放。规则如下。

## 1. 单位与归档

- **一堂课的小测 = 一套 Sample Quiz**。同一节课里分几轮出题，也合成一套；不同课次不合并。
- 存放在 `07_题库与模拟考试/04_Sample与历史题目/`，按课次命名：`YYYYMMDD_<课程代码>_WeekN_<星期>_课堂小测Sample_<题数>题_v1审阅版.html`。日期取上课日；课程代码和周次按用户课程的实际情况写。
- 往届录播（例如录制故障后老师改传的上一学期同讲）里的小测，命名加"往届"，在页面和登记中标为"往届课堂样题"。
- 题库 JSON 属于课程数据，放在课程目录和 SKILL 包之外的临时区，用 `build_practice_page.py` 生成作答页，答案在提交后才显示。每题的录播截图写进 `image` 和 `image_caption` 字段，提交后作为答案依据显示（截图里常有投票结果，所以不能在作答前展示）。只填一个词或短语的题，用 `type: "fill"` 加 `accept` 列出老师认可的说法。
- 每门课在同一目录放一份 `YYYYMMDD_<课程代码>_课堂小测Sample索引_v<N>审阅版.md`，列出各套链接、逐题时间戳、答案依据，以及未计分的开放题和词云题。

## 2. 取得题目

1. 用 06 已归档的录播文字稿定位每道题：同时记下**出题时间**和**公布答案时间**。检索 `wooclap`、`QR code`、`next question`、`closing in`、`correct answer` 等词，可用 `scripts/find_exam_mentions.py --tier C`。
2. 用 `scripts/fetch_recording_frames.py` 在出题后、投票关闭或显示结果时截帧，从投屏读出**完整题干和选项原文**。截图要标明录播场次和时间戳。
3. 每题登记以下字段：
   - 课程、课次（周、星期、日期）、录播 entryId；
   - 题号（如投屏上的 `3/13`）、出题时间戳、公布答案时间戳；
   - 题干与选项原文；
   - 题型：单选、多选、填空、开放题或词云；
   - 答案和答案依据（见第 3 节）；
   - 考点；
   - 对应课件页、slide 或 Notebook Cell。

## 3. 答案依据（按优先级）

1. 投屏上平台标出的 **Correct answer**（有截图）；
2. 老师当场口述的答案和讲解（有时间戳）；
3. 两者都没有时，写"课件证据支持的本地推定"，给出课件页码和理由，不冒充老师答案。

不能用全班投票最多的选项推断答案。投票比例可以记录，作为"当场答对率"参考。

## 4. 与考试的关系

- 老师说"考试题目与课堂小测相似"时，在 06 来源状态和 06c 考试汇报里标注出处。这类课堂样题应作为 07 模拟卷出题风格的首要参照。
- 老师说"不会出原题、只出同类题"时，模拟卷只模仿考点和题型，不复制原题；原题只出现在课堂样题这一套里。
- 开放题和词云题照样登记。如果老师说过考试不会出这种题型，就不放进自动判分，只保留为讲解材料。
- 06c 考试汇报第 5 段的"课堂小测"部分，直接引用这些课堂样题（题目、答案依据、截图），并链接到对应的作答页。

## 5. 验收

- 题数与录播中实际出题数一致。没出完、没公布答案或画面不可读的题，单独列为缺口，不补编。
- 题干、选项与截图逐字核对；答案依据都有截图或时间戳。
- 作答页按 [出题与验收细则](question-bank-contract.md) 的状态机和浏览器检查执行。
