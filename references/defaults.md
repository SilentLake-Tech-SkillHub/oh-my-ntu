# 默认目录与命名合同

这些设置均可由用户当前 Prompt 覆盖。建立或整理既有课程前，核对当前实体、文件引用、版本状态和用户指定目录；仅有命名合同并不授权批量迁移、删除或重命名。获得授权迁移、改名或复制时，先在课程目录外备份受影响的文件与引用它们的文档，记录操作前后的 SHA-256 并逐一比对，再更新全部引用；Tutorial 副本同样用哈希与 01 正本核对。

```text
01_课程课件/
├── 00_课程说明/、00_课程案例/        （跨周材料，有才建）
└── WeekN_<主题>/
    └── 讲义/、视频/、Notebook/、Tutorial/  （按用途，有才建）
02_大作业/
【预习用】03_Notebook课件中英文对照解析/
04_复习笔记/
05_考前速记与关键术语宝典/
06_课堂录播字幕/
07_题库与模拟考试/
```

01 默认两级分类，根目录不平铺文件：一级按课次 `WeekN_<主题>/`（跨周材料放 `00_课程说明/`、`00_课程案例/`），二级按用途 `讲义/`、`视频/`、`Notebook/`、`Tutorial/`，只建有内容的目录；章节与周的对应须有官方日程、平台分组或用户确认，逐个文件核对内容后再归类，详见 01 子 SKILL。教师源文件名为 `WeekN_Weekday_主题.扩展名`；星期必须有课程表或正式来源，不猜，证据不足时保留教师原文件名。依赖原相对文件名的配套代码保留必要例外，不改写教师内容。

02–07 默认采用 `YYYYMMDD_课程代码_文件用途_版本或状态_内容范围或载体.扩展名`。日期取官方发布日期、取得日期或实际生成/修订日期，标明依据，不猜。名称要让零背景用户在打开前看懂内容：ZIP 写明完整项目包、代码包或报告包；截图写明主题和实际学生平台来源；文件夹与对应 ZIP 分别标明载体。未经内容验收不写 `final`，使用 `v1审阅版` 等真实状态。教师正式术语可保留英文，其他说明用自然、准确的语言。原件与 AI 派生件分开，只有一个真实实体归属；唯一例外是 Tutorial 原件：01 为正本，03 的 Tutorial 合集放逐字节相同的副本（见 03 子 SKILL 第 8 节）。

全课程来源核对至少区分官方公告、课件和配套文件、录播字幕三类。每类建立官方清单与本地实体的对应关系；缺失、尚未发布、仅用户转述或本地推定都要明示。不要把目录存在、文件数量或自动检查等同内容验收。

课程目录默认只留教师原件、用户需要的成品及其离线显示或运行必需的资源。为制作成品临时生成的 Plan/流水目录、构建脚本、校验值清单、截图、缓存及导入用文件，不因制作过程而成为课程交付物；放在课程目录和 SKILL 包之外的临时工作区（如 `流程管理/执行计划/<计划名>/构建脚本/`）。用户内容验收前保留在临时区以便返工；用户验收后，核对成品不再依赖再清理。`.ics` 等导入文件仅在用户明确要求日历导入或保留文件时制作；仅作导入中间件的，在确认日历事件实际生效后清理本地中间件。不得因此删除教师原件、用户已有文件、Notebook 引用的原页图片或其他仍被成品依赖的资源；已有课程目录的清理仍按用户当次要求确定范围。

SKILL 包的 `scripts/` 只放被 SKILL 正文引用、不写死课程路径、课程代码或题目内容的通用工具；课程数据以参数或外部文件传入。课程专用构建脚本、题库数据与 `__pycache__` 等缓存不得进入 SKILL 包。每次改动 SKILL 包后，扫描 `scripts/` 中的绝对路径、课程代码与缓存目录，结果为 0 才算包结构校验通过。
